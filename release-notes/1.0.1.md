Maintenance release for the in-app updater.

Highlights
- In-app updates: 1.0.0 installations can now update to 1.0.1 from inside the app.
- Packaging: setup and portable builds rebuilt from the same source with matching version metadata.
- Compatibility: no changes to playback, media library, or the redesigned interface.
- Existing settings, library, and playlists are preserved.

Requirements
------------
Windows 10 (1809 or later) or Windows 11, 64-bit. English UI.

Notes
-----
- The binaries are not code-signed yet: SmartScreen may show "Windows protected your PC" - choose More info, then Run anyway.
- VLC Reimagined is an independent fork of VLC, not affiliated with or endorsed by VideoLAN. VLC is a trademark of VideoLAN.
- The portable archive is self-contained; no installation or administrator rights required.
- Users still on the old 4.0.0 development build must install 1.0.1 manually once. 1.0.0 and newer update in-app.
- Source code: https://github.com/rabiahmed8/vlc-reimagined (GPLv2 or later)
