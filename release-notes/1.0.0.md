VLC Reimagined 1.0.0 — first public release
===========================================

VLC's engine, in a redesigned interface.

Highlights
----------
- New player window: dark, frameless, minimal top bar, rebuilt menus and
  controls that fade out in fullscreen and in the mini player.
- Media library with Home, Videos, Music, Playlists, Folders, Network,
  Streams and Recent views, search and thumbnails.
- Queue panel with per-item move up/down buttons.
- Audio and subtitle track panels, plus a subtitle sync timeline.
- Video adjustments and a full equalizer.
- Redesigned settings, first-run onboarding, dark/light/system theme,
  accent colour and interface scaling.
- Keyboard shortcuts reference from the main menu and the right-click menu.
- Portable mode: put an empty `portable` folder next to `vlc.exe`.
- Installs side by side with the official VLC: own program folder, settings,
  registry keys and file associations.
- Built-in updater with an optional automatic daily check.
- Fixed a crash in the adjust video filter on extreme luma values.

Requirements
------------
Windows 10 (1809 or later) or Windows 11, 64-bit. English UI.
